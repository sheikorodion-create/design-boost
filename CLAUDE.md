# Design Boost

Сайт-архив дизайн-разминок Родиона Шейко и Ивана Коптелина. Отвечай и пиши интерфейс по-русски. Пользователи — дизайнеры, поэтому в ответах называй конкретные значения: px, цвета, файлы.

## Стек и публикация

- Статика без сборки: `index.html`, `styles.css`, `data.js`, `app.js`, hash-роутинг (`#/boost/<id>`, `#/partners`).
- Сайт публикуется через GitHub Pages из ветки `main`, папка `/ (root)`. Любой пуш в `main` сразу идёт на сайт, поэтому работаем в ветках и вливаем через Pull Request.
- Репозиторий публичный: токены, пароли и персональные данные в него не класть.
- Работы участников не публикуем: папка `works/` в `.gitignore`.
- После правок проверяй результат в браузере на ширине 375 px и на десктопе от 1024 px.

## Дизайн

Источник — файл «Контент» в Фигме, страница «Design boost»: https://www.figma.com/design/edUsAxyYo4smO8KnsJm3vY

- Шрифт только Golos Text.
- Ровно пять текстовых стилей, переменные в начале `styles.css`: `--t-title` (28/1, 700, капс), `--t-logo` (24, 700), `--t-sub` (16/1.15, 700), `--t-text` (14/1.3), `--t-caption` (12/1.3). Новые не добавлять. Исключение: крупный заголовок 44 px на десктопе.
- Цвета текста: `--ink` #111214 и `--mute` #6B727E. На цветных карточках весь текст `--ink`. Фон `--bg` #F8F8F8, белые блоки `--paper`.
- Отступы чётные. Поля страницы `--gutter` 16 px на всех ширинах. Контент до 1180 px, шапка, меню и подвал той же ширины.
- Карточки: скругление 20 px, внутренние поля 20 px, зазор 12 px.
- Стрелка только из `icons/arrow.svg`.
- Висячие предлоги, тире и разряды чисел обрабатывает `typograph()` в `app.js`: в текстах пиши обычные пробелы.

## Анимации

- Только `transform` и `opacity`. Кривые — переменные `--ease-*` из `styles.css`.
- Наведение только внутри `(hover: hover) and (pointer: fine)`. Нажатие на карточку — `scale: 0.98`.
- Загиб карточек при прокрутке — только на ширине меньше 900 px.
- Всё движение уважает `prefers-reduced-motion`.

## Контент

- Заглавная буква в начале значений, пунктов и подписей.
- Обложки: 1600 px по ширине, пропорция 4:3, JPG. Лежат в `images/<id задания>/01.jpg`.
- Победителей, призы и голосования на сайте пока не упоминаем.

## Мини-приложение в Telegram (ветка `mini-app`)

Прототип без сервера, данные в `localStorage`, код в `community.js`. Решения:

- Вход только через Telegram-мини-приложение, без отдельной регистрации.
- Загружать можно только картинки, до 5 на работу. Работа публикуется после одобрения модератором.
- Пока задание идёт, чужие работы видны только тем, кто загрузил свою и подтвердил риск зафреймиться.
- После дедлайна загрузка закрывается, одобренные работы видны всем.
- Реакция одна, 🔥; на свою работу поставить нельзя.

Дальше нужны бот, сервер, база PostgreSQL и S3-хранилище в России (план — Timeweb Cloud). Подлинность пользователя проверяется на сервере по `initData`. Подписку сначала планируем через Tribute: доступ по участию в закрытом канале. В базе хранить дату окончания доступа.
