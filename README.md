# Design Boost

Сайт-архив дизайн-разминок. Адрес: https://sheikorodion-create.github.io/design-boost/

## Как запустить у себя

```bash
python3 -m http.server 4173
```

Затем откройте http://localhost:4173. Сборка не нужна, сайт — обычные файлы.

## Как вносить изменения

1. Перед началом сделайте Pull, чтобы забрать чужие правки.
2. Создайте отдельную ветку. Не работайте прямо в `main`: всё, что туда попадает, сразу публикуется на сайте.
3. Проверьте изменения у себя, сделайте Commit и Push.
4. Откройте Pull Request и влейте его в `main`, когда всё в порядке.

## Как устроен проект

- `index.html` — каркас страницы, подвал.
- `data.js` — все задания, партнёры и цифры. Новая разминка — новый объект в `BOOSTS`.
- `app.js` — страницы, переходы, меню.
- `styles.css` — стили. Текстовые стили и цвета заданы переменными в начале файла.
- `images/<id задания>/` — обложки заданий.
- `scripts/build-single.py` — собирает весь сайт в один файл для показа на телефоне.

Правила дизайна и принятые решения — в [CLAUDE.md](CLAUDE.md).
